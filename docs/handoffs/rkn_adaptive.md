# Embedded velocity-independent Runge--Kutta--Nystrom methods

This wave ports `DPRKN4`, `DPRKN5`, `DPRKN6FM`, `DPRKN8`, `DPRKN12`,
`ERKN4`, `ERKN5`, and `ERKN7` from OrdinaryDiffEqRKN at revision
`211142263781255a9aa2f910f6760b9f18ec29c8`.

The follow-up wave adds `FineRKN4` and `FineRKN5` through the same controller
with their velocity-stage `abar` matrices, so both retain support for genuinely
velocity-dependent acceleration. It also adds `DPRKN6`, including the pinned
sixth-order free continuous extension (`R` and `Rp`). The latter is used for
`save_at` sampling and continuous-callback root localization rather than only
being stored as unused metadata.

The exact `a`, `b`, `bp`, `btilde`, `bptilde`, `c`, order, and
`pos_only_error` metadata are generated into
`src/rkn_adaptive_coefficients.rs` by
`scripts/generate_rkn_adaptive_coefficients.jl`. The generator loads the
pinned Julia tableaus directly, emits their `Float64` values in row-major
order, and records the pin in the generated file.

The shared Rust kernel keeps position and velocity partitions separate. Every
attempt recomputes its stage ladder into workspace storage, forms both primary
updates, and evaluates the embedded position/velocity defect with a scaled RMS
norm. `ERKN5` follows upstream's position-only estimator. Rejected candidates
never replace the accepted state or reach callbacks and output recording.
Accepted steps use order-aware proportional control and support both time
directions; setting `adaptive = false` uses the same primary tableau with the
requested fixed step.

`tests/rkn_adaptive.rs` covers adaptive accuracy, forced rejection, fixed mode,
backward time, and public spellings. `tests/julia/rkn.jl` compares all eight
fixed endpoints directly with the pin and also checks their adaptive endpoints
at tight tolerances.

`IRKN3` and `IRKN4` use a separate fixed-step history kernel generated by
`scripts/generate_irkn_coefficients.jl`; its bootstrap, cache seeds, history
shifts, final partial-step fallback, and callback-discontinuity restart are
documented in `docs/IRKN3_IRKN4_PORTING_NOTES.md`.
